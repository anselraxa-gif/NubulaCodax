# NubulaCodax

Un langage de programmation généraliste, de bas niveau, conçu pour être d'une rigueur absolue et d'une complexité sans compromis.

## Objectif
Offrir un contrôle total, un typage ultra-statique intransigeant, et une structure syntaxique impitoyable où la moindre erreur bloque net la compilation.

## Extension des fichiers
Les fichiers sources de NubulaCodax utilisent l'extension `.ncx`.
